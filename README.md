# DevLinks Profile Hub

![Profile Hub](https://img.shields.io/badge/Profile%20Hub-Personal%20Links-blue?style=for-the-badge&logo=link&logoColor=white)

## Overview

This is my first front-end development study project - a clean, responsive profile hub inspired by LinkTree. This project serves as a centralized location for all my professional and social media links with a sleek interface that includes a dynamic light/dark mode toggle.

## Features

- **Dual Theme Support**: Seamlessly switch between light and dark modes
- **Responsive Design**: Adapts perfectly to both mobile and desktop screens
- **Animated Elements**: Smooth transitions and hover effects enhance user experience
- **Social Media Integration**: Direct links to all my professional platforms
- **Custom Styling**: Minimalist design with a focus on accessibility and usability

## Technologies Used

- HTML5
- CSS3 (with Flexbox)
- Vanilla JavaScript
- CSS Variables for theming
- CSS Animations and transitions
- Ion Icons for social media icons

## What I Learned

This project was fundamental in developing my skills in:
- Building responsive layouts
- Implementing theme switching functionality
- Working with CSS variables and custom properties
- Creating smooth animations and transitions
- Proper HTML semantic structure

## Getting Started

Clone the repository and open `index.html` in your browser to view the profile hub:

```bash
git clone https://github.com/NatanMoura77/LinkProfile.git
cd devlinks-profile
```

No build process or dependencies required!

*This project was created as part of my front-end development learning journey. Feel free to use it as inspiration for your own profile hub!*
